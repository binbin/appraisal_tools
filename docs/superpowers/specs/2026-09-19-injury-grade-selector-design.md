# 工伤级别选择工具 — 设计规格

**日期：** 2026-09-19  
**标准依据：** GB/T 16180—2014《劳动能力鉴定 职工工伤与职业病致残等级》  
**状态：** 已批准

## 1. 目标

为鉴定专家提供快速查找并选中工伤伤残条款的辅助工具。专家通过 Input 旁的「辅助工具」打开右侧抽屉，按国标五大门类浏览或搜索条款，单选后将「条款编号 + 等级」写入 Input。

## 2. 技术选型

- Vite + React（函数组件）+ TypeScript
- Ant Design
- 包管理：pnpm
- Form：非受控 Input
- 数据：本地静态条款数据，无后端

## 3. 界面与交互

### 3.1 主区域

- 一行布局：`Input`（非受控，可手改）+ 「辅助工具」按钮
- Input 占位：`请输入或点辅助工具选择条款`

### 3.2 右侧抽屉

- 宽度约 480px
- 标题：`工伤伤残等级条款（GB/T 16180—2014）`
- 顶部：关键词搜索框（匹配条款编号、等级、摘要）
- 门类 Tabs（按国标五科）：
  1. 神经内科、神经外科、精神科门
  2. 骨科、整形外科、烧伤科门
  3. 眼科、耳鼻喉科、口腔科门
  4. 普外科、胸外科、泌尿生殖科门
  5. 职业病内科门
- 条款列表：展示当前门类 + 搜索过滤后的条目
  - 每行：`编号` · `等级` · `摘要`
  - 当前选中行使用不同背景色标识
  - 点击一行：写入 Input → 关闭抽屉

### 3.3 选择与写入

- **单选**：点选即生效，关闭抽屉
- **写入格式**：`{code} {grade}`，例如 `5.9.2 九级`
- 搜索范围：当前门类内；清空搜索恢复该门类全部条款

### 3.4 状态记忆

- 再次打开抽屉：记住上次选中的门类
- 若 Input 已有合法 `编号 等级`，对应条款行保持高亮
- 切换门类时清空搜索词

## 4. 数据模型

```ts
type SpecialtyCategory =
  | "neuro_psych"      // 神经内/外/精神科门
  | "ortho_plastic"    // 骨科/整形/烧伤科门
  | "eye_ent_oral"     // 眼/耳鼻喉/口腔科门
  | "general_urology"  // 普外/胸外/泌尿生殖科门
  | "occupational";    // 职业病内科门

type InjuryClause = {
  id: string;           // 唯一键，如 "5.9.2-1"
  code: string;         // 条款编号，如 "5.9.2"
  grade: string;        // 等级，如 "九级"
  summary: string;      // 摘要条文
  category: SpecialtyCategory;
};
```

### 4.1 数据范围

首版每个门类提供代表性条款子集（覆盖常见一～十级条目），数据结构按国标可扩展；后续可用完整条款表替换数据文件，无需改 UI。

## 5. 模块结构

```
src/
  App.tsx
  components/
    InjuryGradeField.tsx      # Input + 辅助工具按钮
    ClauseAssistDrawer.tsx    # 抽屉：搜索 / 门类 / 列表
  data/
    gb-t16180-2014.ts         # 条款静态数据
  types/
    clause.ts                 # 类型定义
  utils/
    formatClause.ts           # 格式化为「编号 等级」
```

## 6. 数据流

1. 用户点击「辅助工具」→ 打开抽屉
2. 按当前门类 + 关键词过滤条款列表
3. 用户点击某条款
4. `formatClause(clause)` → `"编号 等级"`
5. 通过 Input 的 ref 写入 value（保持非受控），然后关闭抽屉

## 7. 边界情况

| 场景 | 处理 |
|------|------|
| 搜索无结果 | 列表空状态：「无匹配条款」 |
| Input 手改 | 允许；辅助工具再次选择会覆盖 |
| 非法 Input 内容 | 打开抽屉时不高亮任何行 |
| 门类切换 | 清空搜索，展示新门类全部条款 |

## 8. 非目标（首版不做）

- 多选条款
- 后端 API / 数据库
- 登录与权限
- 完整国标逐条全量录入（仅做可扩展子集）

## 9. 验收标准

1. 点「辅助工具」打开右侧抽屉，可见五大门类 Tabs
2. 切换门类后列表内容正确更新；选中行背景高亮
3. 搜索可按编号 / 摘要过滤当前门类条款
4. 点选条款后 Input 值为 `编号 等级`，抽屉关闭
5. Input 为非受控，支持手改

## 10. 决策记录

| 决策点 | 结论 |
|--------|------|
| 写入内容 | 条款编号 + 等级（如 `5.9.2 九级`） |
| 选择方式 | 单选，点选即写并关抽屉 |
| 门类划分 | 国标五科门类 |
| 搜索 | 首版支持关键词搜索 |
| 架构 | 静态 JSON/TS 数据 + 前端筛选 |
