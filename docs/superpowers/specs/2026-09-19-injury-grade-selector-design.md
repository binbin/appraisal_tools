# 工伤级别选择工具 — 设计规格

**日期：** 2026-09-19  
**标准依据：** GB/T 16180—2014《劳动能力鉴定 职工工伤与职业病致残等级》  
**状态：** 已批准（含 2026-09-19 修订）

## 1. 目标

为鉴定专家提供快速查找并选中工伤伤残条款的辅助工具。专家通过「辅助工具」打开右侧抽屉，按国标五大门类浏览或搜索条款；每次点选将「条款编号 + 等级」以换行方式追加到文本列表。悬停已选文字时，Tooltip 显示条款原文。

## 2. 技术选型

- Vite + React（函数组件）+ TypeScript
- Ant Design
- 包管理：pnpm
- 数据：本地静态条款数据，无后端

## 3. 界面与交互

### 3.1 主区域

- **无 Input**
- 「辅助工具」按钮
- 下方：已选条款文本列表
  - 初始占位：`尚未选择条款`
  - 每行展示：`{code} {grade}`（如 `5.9.2 九级`）
  - 悬停行文字：`Tooltip` 显示该条款 `summary`（原文摘要）
  - 行末：删除图标，移除该行

### 3.2 右侧抽屉

- 宽度约 480px
- 标题：`工伤伤残等级条款（GB/T 16180—2014）`
- 顶部：关键词搜索框（匹配条款编号、等级、摘要）
- 门类 Tabs（按国标五科）：
  1. 神经内科、神经外科、精神科门
  2. 骨科、整形外科、烧伤科门
  3. 眼科、耳鼻喉科、口腔科门
  4. 普外科、胸外科、泌尿生殖科门
  5. 职业病内科门
- 条款列表：当前门类 + 搜索过滤后的条目
  - 每行：`编号` · `等级` · `摘要`
  - 已在结果列表中的条款使用不同背景色标识
  - 点击一行：追加到主区域文本列表（换行），**抽屉保持打开**
  - 点遮罩或关闭按钮才关闭抽屉

### 3.3 选择与写入

- **追加多选**：每次点选换行追加一行
- **去重**：同一条款 `id` 已存在则不再追加（可轻提示「已添加」）
- **写入格式**：`{code} {grade}`，例如 `5.9.2 九级`
- **Tooltip 原文**：已选行悬停显示对应 `summary`
- 搜索范围：当前门类内；清空搜索恢复该门类全部条款

### 3.4 状态记忆

- 再次打开抽屉：记住上次选中的门类
- 已选条款在抽屉列表中保持高亮背景
- 切换门类时清空搜索词

## 4. 数据模型

```ts
type SpecialtyCategory =
  | "neuro_psych"      // 神经内/外/精神科门
  | "ortho_plastic"    // 骨科/整形/烧伤科门
  | "eye_ent_oral"     // 眼/耳鼻喉/口腔科门
  | "general_urology"  // 普外/胸外/泌尿生殖科门
  | "occupational";    // 职业病内科门

type InjuryClause = {
  id: string;           // 唯一键，如 "5.9.2-1"
  code: string;         // 条款编号，如 "5.9.2"
  grade: string;        // 等级，如 "九级"
  summary: string;      // 原文摘要（列表展示 + Tooltip）
  category: SpecialtyCategory;
};

type SelectedClause = InjuryClause; // 已选列表项，保留完整字段供 Tooltip
```

### 4.1 数据范围

首版每个门类提供代表性条款子集（覆盖常见一～十级条目），数据结构按国标可扩展；后续可用完整条款表替换数据文件，无需改 UI。

## 5. 模块结构

```
src/
  App.tsx
  components/
    InjuryGradeField.tsx      # 辅助工具按钮 + 已选文本列表
    SelectedClauseList.tsx    # 已选行：文字 + Tooltip + 删除
    ClauseAssistDrawer.tsx    # 抽屉：搜索 / 门类 / 列表
  data/
    gb-t16180-2014.ts         # 条款静态数据
  types/
    clause.ts                 # 类型定义
  utils/
    formatClause.ts           # 格式化为「编号 等级」
```

## 6. 数据流

1. 用户点击「辅助工具」→ 打开抽屉
2. 按当前门类 + 关键词过滤条款列表
3. 用户点击某条款
4. 若 `id` 未在已选列表中：`formatClause` 展示文本追加一行，并保留完整条款供 Tooltip
5. 若已存在：不追加，可选 message 提示「已添加」
6. 抽屉保持打开；用户可继续选择或手动关闭
7. 点击已选行删除图标 → 从列表移除该行，抽屉内高亮同步取消

## 7. 边界情况

| 场景 | 处理 |
|------|------|
| 搜索无结果 | 列表空状态：「无匹配条款」 |
| 重复点选同一条款 | 不追加，提示「已添加」 |
| 尚未选择 | 占位文案：「尚未选择条款」 |
| 删除最后一项 | 恢复占位文案 |
| 门类切换 | 清空搜索，展示新门类全部条款 |

## 8. 非目标（首版不做）

- 写入 Input / 表单提交对接
- 后端 API / 数据库
- 登录与权限
- 完整国标逐条全量录入（仅做可扩展子集）
- 已选列表拖拽排序

## 9. 验收标准

1. 无 Input；点「辅助工具」打开右侧抽屉，可见五大门类 Tabs
2. 切换门类后列表内容正确更新；已选条款在抽屉内背景高亮
3. 搜索可按编号 / 摘要过滤当前门类条款
4. 点选条款后主区域换行追加 `编号 等级`，抽屉不关闭
5. 悬停已选文字，Tooltip 显示条款原文摘要
6. 行末删除可移除该项；重复点选不重复追加

## 10. 决策记录

| 决策点 | 结论 |
|--------|------|
| 展示位置 | 文本列表，无 Input |
| 写入内容 | 条款编号 + 等级（如 `5.9.2 九级`） |
| 选择方式 | 追加多选，换行增加；同 id 去重 |
| Tooltip | 悬停已选文字显示 summary 原文 |
| 删除 | 首版支持行末删除 |
| 抽屉 | 点选后保持打开 |
| 门类划分 | 国标五科门类 |
| 搜索 | 首版支持关键词搜索 |
| 架构 | 静态 TS 数据 + 前端筛选 |
